# 橡皮大战（Three.js 网页版）

课桌上的弹橡皮对战。轮流用手指弹自己的橡皮，把别人弹下课桌就赢。

- **本地对战**：2–6 个位置，每个位置可以是玩家或电脑（简单 / 普通 / 困难）。同一台设备轮流弹。
- **联机对战**：最多 6 人，房间号加入，空位可以加电脑。
- **规则**：2 人三局两胜；3–6 人打 3 局，按名次和撞下人数算总分。
- 8 块橡皮各有属性和技能。每次轮到自己 +1 能量（上限 3），撞下别人再 +1，技能消耗 1–3 点。

## 运行

```bash
npm install
npm run dev          # 本机开发，终端会显示局域网地址
```

在平板上试玩：电脑和平板连同一个 Wi-Fi，用平板浏览器打开终端里显示的 `http://192.168.x.x:5173`。

```bash
npm run build         # 输出 dist/，部署到任意静态托管即可
npm run build:single  # 输出 dist-single/index.html 单文件
npm run typecheck
npx tsx tools/balance-sim.ts 8 normal   # 电脑两两对打，输出胜率矩阵
```

## 联机设置

1. 到 [GoEasy](https://www.goeasy.io) 注册，创建一个应用。
2. 把应用的 appkey 和区域填进 `src/net/netconfig.ts`。
3. `npm run build` 后把 `dist/` 部署到网上（GitHub Pages、Cloudflare Pages，或有备案域名时用 EdgeOne Pages）。
4. 一个人「创建房间」，把 5 位房间号告诉别人，别人在「联机对战」里输入加入。也可以直接分享 `网址?room=房间号`。

没填 appkey 时，可以勾选「本机多标签页测试」，在同一个浏览器里开几个标签页联机，用来试流程。

联机的做法：所有人用同样的输入各自模拟，房主每次结算后广播最终位置，大家以房主为准。房主掉线 12 秒后，座位顺序里下一个在线的玩家接任；掉线的玩家由电脑代打，回来后自动接上。

## 操作

- **弹指**：在橡皮周围的虚线圈里起手，手指快速划过橡皮。划得越快弹得越远；弹在中心走直线，弹在角上会边转边走。在橡皮上起手再划出去算作「推」。
- **技能**：轮到自己时点右下角的技能按钮（键盘空格或 Q），亮起后这次弹射生效。「蓄势」点了直接生效并结束这一次。「刹车」在橡皮滑动时点屏幕任意处。
- 右上角是全屏和菜单按钮。键盘 F 切换全屏，Esc 打开菜单。
- iPhone 不支持网页全屏：用「分享 → 添加到主屏幕」，从桌面图标打开就是全屏。

## 调数值

所有数值都在 `src/core/config.ts`：角色属性（1–5 分）、属性分对应的物理参数、技能、能量规则、弹指手感。改完用 `tools/balance-sim.ts` 跑胜率看效果。游戏内「设置 → 弹指灵敏度」可以整体调节力度。

## 目录

```
src/
  core/      纯逻辑：数值配置、物理（Rapier2D 确定性版）。不依赖 DOM
  game/      对局规则（match.ts）、人机（ai.ts）
  net/       联机：传输层（GoEasy / 本机多标签页）、房间与同步（online.ts）
  render/    Three.js 场景、橡皮模型、程序化贴图
  input/     弹指手势识别
  ui/        全屏管理
  main.ts    界面与流程
tools/
  balance-sim.ts   平衡模拟
```
