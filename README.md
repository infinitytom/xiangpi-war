# 橡皮大战（Three.js 网页版）

课桌上的弹橡皮对战。轮流用手指弹自己的橡皮，把别人弹下课桌就赢。

- **本地对战**：2–6 个位置，每个位置可以是玩家或电脑（简单 / 普通 / 困难）。同一台设备轮流弹。
- **联机对战**：最多 6 人，房间号加入，空位可以加电脑。
- **规则**：2 人三局两胜；3–6 人打 3 局，按名次和撞下人数算总分。
- 8 块橡皮各有属性和技能。每次轮到自己 +1 能量（上限 3），撞下别人再 +1，技能消耗 1–3 点。
- 每局第一弹只有六成力；连续几轮没人落桌，力度上限会逐步提高，避免僵局。
- 甩动时橡皮外圈显示实时力度（绿 → 黄 → 红，红色闪烁 = 满力）。

## 运行

```bash
npm install
npm run dev          # 本机开发，终端会显示局域网地址
```

在平板上试玩：电脑和平板连同一个 Wi-Fi，用平板浏览器打开终端里显示的 `http://192.168.x.x:5173`。

```bash
npm run build         # 输出 dist/，部署到任意静态托管即可
npm run build:single  # 输出 dist-single/index.html 单文件
npm run typecheck
npx tsx tools/balance-sim.ts 8 normal   # 电脑两两对打，输出胜率矩阵
```

## 在线地址与联机

- 在线玩：https://infinitytom.github.io/xiangpi-war/ （入口页在 GitHub Pages，脚本和图片走 jsDelivr CDN，国内加载更快；CDN 30 秒没加载成功会自动回退）
- 联机默认走 EMQX 的免费公共 MQTT 服务器（国内节点在腾讯云上海），**不需要注册**。一个人「创建房间」，把 5 位房间号告诉别人，或直接分享 `网址?room=房间号`。
- 想换成 GoEasy：在 `src/net/netconfig.ts` 填 appkey，填了就优先用 GoEasy。
- 「本机多标签页测试」不联网，只用来在同一浏览器里试流程。

联机的做法：所有人用同样的输入各自模拟，房主每次结算后广播最终位置，大家以房主为准。
房主切到后台时会把房主交给下一位玩家；掉线 12 秒后也会自动换人。掉线或切走的玩家由电脑代打，回来后自动同步。

## 部署

```bash
git worktree add ../gh-pages gh-pages     # 第一次：把 gh-pages 分支检出到旁边的目录
tools/deploy-pages.sh ../gh-pages         # 构建并发布
```

脚本会先单独提交静态资源拿到提交号，入口页再用 `@提交号` 引用 jsDelivr，避免 CDN 缓存旧文件。

## 操作

- **甩出**：手指按住自己的橡皮，朝想去的方向一甩、顺势松手。松手那一下甩得越快飞得越远；按着中间甩走直线，按着角甩会边转边走。手指停住再松开不算出手，可以重来。
- **失手起飞**：力度圈转满一圈后还会进入暗红色的第二圈，甩进第二圈太多（超过满力 15%）橡皮会起飞，越猛飞得越高越远，常常直接飞出桌外。按在橡皮边缘、力度又超过七成时，也会翻着飞出去、方向跑偏。空中不会撞到别人。
- **技能**：轮到自己时点右下角的技能按钮（键盘空格或 Q），亮起后这次弹射生效。「蓄势」点了直接生效并结束这一次。「刹车」在橡皮滑动时点屏幕任意处。
- 右上角是全屏和菜单按钮。键盘 F 切换全屏，Esc 打开菜单。
- iPhone 不支持网页全屏：用「分享 → 添加到主屏幕」，从桌面图标打开就是全屏。

## 调数值

所有数值都在 `src/core/config.ts`：角色属性（1–5 分）、属性分对应的物理参数、技能、能量规则、弹指手感。改完用 `tools/balance-sim.ts` 跑胜率看效果。游戏内「设置 → 弹指灵敏度」可以整体调节力度。

## 目录

```
src/
  core/      纯逻辑：数值配置、物理（Rapier2D 确定性版）。不依赖 DOM
  game/      对局规则（match.ts）、人机（ai.ts）
  net/       联机：传输层（GoEasy / 本机多标签页）、房间与同步（online.ts）
  render/    Three.js 场景、橡皮模型、程序化贴图
  input/     弹指手势识别
  ui/        全屏管理
  main.ts    界面与流程
tools/
  balance-sim.ts   平衡模拟
```
